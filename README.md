# Netcam Simulator

โปรแกรมจำลองกล้อง IP (IP Camera Emulator) สำหรับงานฝึกอบรมและทดสอบระบบ VMS / NVR
จำลองกล้องสไตล์ **Dahua** และ **Hikvision** บนคอมพิวเตอร์ Windows เครื่องเดียว
เพื่อให้ผู้เรียนฝึกเพิ่มกล้อง ดูสตรีม RTSP และดึง snapshot ได้โดยไม่ต้องใช้ฮาร์ดแวร์จริง

> **คำเตือน**: โปรแกรมนี้ใช้เพื่อการศึกษาและการทดสอบเท่านั้น
> รหัสผ่านและ path ในโปรแกรมเป็นค่าทดสอบ ห้ามนำไปใช้กับกล้องหรือระบบจริง

---

## คุณสมบัติ

- เลือกการ์ดเครือข่ายและสแกนหา IP ว่างในวงอัตโนมัติ
- ตั้ง IP หลักของการ์ดเป็น static แล้วคืน DHCP ให้เมื่อปิดโปรแกรม
- เพิ่ม IP alias ให้กล้องจำลองแต่ละตัว
- สตรีม RTSP main และ sub ผ่าน MediaMTX และ ffmpeg
- HTTP snapshot ตามรูปแบบของ Dahua และ Hikvision พร้อม Basic Auth
- แดชบอร์ดบนเบราว์เซอร์ อัปเดตสถานะด้วย AJAX ทุก 3 วินาที
- เปิดและปิดกล้องแต่ละตัวได้จากหน้าเว็บ
- ไอคอนใน System Tray พร้อมเมนูเปิดแดชบอร์ดและออกจากโปรแกรม
- ตัวติดตั้ง Windows เปิด Firewall ให้โปรแกรมอัตโนมัติ

## ความต้องการของระบบ

- Windows 10 หรือ Windows 11 (64-bit)
- สิทธิ์ผู้ดูแลระบบ (Administrator)
- การ์ดเครือข่ายที่เชื่อมต่อกับ LAN หรือ Wi-Fi ที่มี DHCP
- CPU ที่รองรับการเข้ารหัสวิดีโอ (แนะนำ 4 แกนขึ้นไปสำหรับกล้องหลายตัว)

## การติดตั้ง (สำหรับผู้ใช้ทั่วไป)

1. ดาวน์โหลด `NetcamSimulator_Setup_<เวอร์ชัน>.exe` จาก Releases
2. ดับเบิลคลิกไฟล์และกด Yes ที่หน้าต่าง UAC
3. เลือกการเข้าถึง Firewall
   - **เฉพาะเครือข่ายส่วนตัว (Private)**: แนะนำ
   - **ทุกเครือข่าย**: ใช้เมื่อเครื่องอื่นต้องเข้าถึงจากต่างวง
   - **ไม่เปิด**: ตั้งค่าเองภายหลัง
4. เสร็จแล้วจะมีทางลัดบน Desktop และ Start Menu

## วิธีใช้งาน

### 1. เปิดโปรแกรม
ดับเบิลคลิกทางลัด **Netcam Simulator** แล้วกด Yes ที่หน้าต่าง UAC
- Splash จะขึ้น 3 วินาที
- หน้าตั้งค่าจะโหลดรายการการ์ดและสแกน IP ว่างอัตโนมัติ

### 2. ตั้งค่าเครือข่าย
- เลือกการ์ดที่เชื่อมต่อกับเครื่องที่ VMS หรือผู้เรียนจะใช้งาน
- ดูช่วง **IP ว่างในวง** ที่แสดงเป็นช่วงสั้น ๆ เช่น `192.168.1.2–16, 192.168.1.18–40`
- ติ๊กกล้องที่ต้องการเปิด และกรอก IP ให้แต่ละตัวจากช่วงว่างนั้น

### 3. เริ่มระบบ
กด **เริ่มระบบ** โปรแกรมจะ
1. ตรวจ IP ที่กรอกว่าไม่ชนกับ router, IP หลักของการ์ด หรืออุปกรณ์อื่น
2. ตั้ง IP หลักของการ์ดเป็น static ตามค่าที่ได้จาก DHCP
3. เพิ่ม IP ของกล้องเป็น alias บนการ์ด
4. เปิด MediaMTX, สตรีมวิดีโอ, HTTP ของกล้อง และ Web UI
5. เปิดแดชบอร์ดในเบราว์เซอร์ให้อัตโนมัติ

เมื่อเริ่มสำเร็จ หน้าตั้งค่าจะซ่อน และไอคอนจะขึ้นที่ System Tray

### 4. ใช้งานแดชบอร์ด
เปิดได้จาก `http://127.0.0.1:9090` หรือคลิกขวาไอคอน tray แล้วเลือก **เปิดแดชบอร์ด**

ในแต่ละกล้องจะมี
- **สถานะ** Main, Sub, HTTP และ IP บนการ์ด
- **URL RTSP** สำหรับ VMS หรือ VLC คัดลอกได้ด้วยปุ่ม คัดลอก
- **ลิงก์ Snapshot** ที่รูปแบบเหมือนกล้องจริง
- **ดูภาพ** ดึงภาพล่าสุดมาแสดงในกล่องตัวอย่าง
- **เปิดกล้อง / ปิดกล้อง** เปิดหรือหยุดสตรีมของกล้องนั้น

### 5. ทดสอบจาก VLC หรือ VMS
เปิด VLC แล้วเลือก Media > Open Network Stream ใส่ URL จากแดชบอร์ด เช่น
```
rtsp://admin:admin1234@192.168.1.241:8554/cam/realmonitor/main
rtsp://admin:admin1234@192.168.1.242:8554/Streaming/Channels/101
```

หรือเปิดลิงก์ snapshot ในเบราว์เซอร์ จะมีหน้าต่างให้กรอก user และรหัส
```
http://192.168.1.241:8080/cgi-bin/snapshot.cgi?channel=1
http://192.168.1.242:8080/ISAPI/Streaming/channels/101/picture
```

### 6. ปิดโปรแกรม
คลิกขวาไอคอน tray แล้วเลือก **ออก** โปรแกรมจะหยุดสตรีมทั้งหมดและคืน DHCP ให้การ์ด

## บัญชีและพอร์ตทดสอบ

| รายการ | ค่า |
|---|---|
| Username | `admin` |
| Password | `admin1234` |
| RTSP | `8554` |
| HTTP ของกล้อง | `80` หรือ `8080` ตาม config |
| Web UI | `127.0.0.1:9090` |

## การตั้งค่า

ไฟล์ตั้งค่าอยู่ในโฟลเดอร์ `config`
- `settings.yaml` ค่าเครือข่าย พอร์ต และ path ของ MediaMTX และ ffmpeg
- `cameras.yaml` รายการกล้อง ยี่ห้อ IP codec ความละเอียด และ path ของสตรีม
- `mediamtx.yml` ค่าของ MediaMTX เปิดเฉพาะ RTSP

หลังจากเปลี่ยนค่า ให้ปิดแล้วเปิดโปรแกรมใหม่

## ไฟล์วิดีโอทดสอบ

วางไฟล์วิดีโอในโฟลเดอร์ `media` แล้วระบุชื่อใน `cameras.yaml` ที่ `media.file`
- ควรใช้คลิปที่สร้างเองหรือมีลิขสิทธิ์เปิด
- **ห้ามใช้วิดีโอที่มีบุคคลหรือพื้นที่ส่วนตัวของผู้อื่นโดยไม่ได้รับอนุญาต**

## การแก้ปัญหาเบื้องต้น

| อาการ | วิธีตรวจ |
|---|---|
| หน้าต่างไม่ขึ้นหรือขอสิทธิ์ไม่ได้ | ตรวจว่า UAC เปิดอยู่ และเลือก Run as administrator |
| `could not bind` ตอนเริ่ม | ตรวจว่าพอร์ต HTTP ไม่ถูกโปรแกรมอื่นใช้ เช่น `netstat -ano \| findstr ":8080"` |
| สตรีมกระตุกเมื่อเปิดหลายกล้อง | ลดความละเอียดหรือเปลี่ยน codec เป็น `h264` ใน `cameras.yaml` |
| Snapshot ช้ามาก | ดู `logs\dahua_demo_01_main.log` ว่ามี `lag` หรือไม่ |
| เครื่องอื่นเข้าไม่ได้ | ตรวจ Firewall ว่าเลือก Private หรือทุกเครือข่าย และ IP อยู่ในวงเดียวกัน |

**ไฟล์ log**
- `logs\netcam.log` เหตุการณ์ของโปรแกรม รวมถึงการหยุดและเริ่มสตรีมใหม่
- `logs\mediamtx.log` ข้อความของ MediaMTX
- `logs\<กล้อง>_<main|sub>.log` ข้อความของ ffmpeg แต่ละสตรีม

## การพัฒนาและการแพ็กโปรแกรม

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python netcam_simulator.pyw
```

แพ็กเป็น exe และตัวติดตั้ง
```bat
.\build_app.bat
"C:\Program Files\Inno Setup 7\ISCC.exe" netcam_setup.iss
```

โครงสร้างโปรเจกต์
```
ipcam-sim/
├─ netcam_simulator.pyw   จุดเริ่มต้น GUI
├─ main.py                โหมดคำสั่ง (CLI)
├─ make_assets.py         สร้างไอคอนจากโลโก้
├─ build_app.bat          แพ็กเป็น exe
├─ netcam_setup.iss       สคริปต์ตัวติดตั้ง Inno Setup
├─ app/                   โค้ดหลัก
├─ config/                ไฟล์ตั้งค่า
├─ assets/                โลโก้และไอคอน
├─ bin/                   mediamtx.exe และ ffmpeg.exe (ไม่รวมใน Git)
├─ media/                 วิดีโอทดสอบ
└─ logs/                  ไฟล์ log
```

## ข้อควรระวังด้านความปลอดภัย

- รหัสผ่าน `admin1234` เป็นค่าทดสอบและแสดงในลิงก์ทั้งหมด ห้ามนำไปใช้กับระบบจริง
- หน้าเว็บผูกกับ `127.0.0.1` ตามค่าเริ่มต้น ถ้าเปิดให้เครื่องอื่นเข้าได้ ต้องเพิ่มการยืนยันตัวตนก่อน
- ไม่แนะนำให้แชร์หน้าจอแดชบอร์ดหรือ log ที่มี URL ซึ่งมีรหัสผ่านติดอยู่
